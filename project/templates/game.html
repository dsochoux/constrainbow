{{ example_board("none") }}

Fill each row with a five-letter word. Only the rows (across) need to be words, not the columns. No regular plurals or regular past tenses.

{{ example_board("colors") }}

Same colour, same letter. If one orange tile is F, every orange tile is F.

Different colours, different letters. Red and orange can't both be F.

Black tiles take any other letter. Never one a colour is using (here F, I, A, P), but they can repeat.

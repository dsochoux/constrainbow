How to play CONSTRAINBOW

Your goal is to create four five-letter words that meet these rules:

  1. Each tile's border color represents a constraint:
    • Colored tiles (non-black) must all contain the same letter.
    • Black tiles can be any letter that isn’t assigned to a colored tile.
  2. Each letter can belong to only one color group (including black).
  3. Black tiles can repeat letters, but colored tiles cannot share letters with black tiles or other colors.
